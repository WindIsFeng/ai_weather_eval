# Methodology

## Case definition

- 以观测登陆时刻判断事件是否属于 2022–2024 年。
- 以 IBTrACS `USA_WIND` 的生命周期最大值是否达到 64 kt 判断强度门槛。
- 每次从海洋到陆地的穿越形成独立 `case_id`；同一风暴可以有多个案例。
- 登陆时允许热带和副热带状态，不纳入已完成温带化后的再次登陆。
- 海岸线穿越由固定版本的 GSHHG 自动检测，并通过版本化覆盖文件进行人工质控。

在产生正式结果前必须冻结 IBTrACS 和 GSHHG 的具体版本，并检查 `USA_WIND` 缺测案例。

## Forecast sampling

名义提前量为 24、48、72、96、120 小时。每个目标时刻匹配最近的 00/06/12/18 UTC
起报周期，允许的最大偏移为 3 小时，同时保存相对于实际登陆的真实提前量。

跨模型结论使用共同可用案例的配对样本。每张表和图同时报告样本数、缺测和追踪失败，
避免模型覆盖差异造成选择偏差。

## Verification families

- 路径：大圆位置误差、沿路径误差、横路径误差。
- 强度：最大风速和最低海平面气压的偏差、MAE、RMSE。
- 登陆：命中/漏报、位置、时间和登陆强度误差。
- 动力场：MSLP、10米风、500 hPa高度以及850/200 hPa风的偏差、RMSE和异常相关。

动力场在统一0.25°网格上验证，并分别计算地球坐标和风暴中心对齐结果。路径/强度提取
使用同一追踪算法，但尽量在模型原生网格上进行。

## Statistical policy

同一风暴的多次登陆不是统计独立样本。置信区间以 `storm_id` 为聚类单元进行 bootstrap，
模型差异在共同样本上配对计算，并按海盆、年份和提前量报告分层结果。
