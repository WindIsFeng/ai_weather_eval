# Adding a model

本项目不运行模型推理；模型预测结果由外部提供。`enabled` 仅表示该模型的
结果文件已经可读取并准备进入验证，预置配置在收到结果前保持 `false`。

1. 在 `configs/models/` 新建模型 YAML，声明文件路径模板、格式、坐标和变量映射。
2. 如果普通 NetCDF/Zarr 映射足够，使用 `generic_xarray`；否则实现 `ModelAdapter` 协议。
3. 将输出规范化为项目规定的维度和变量名，不在指标模块加入模型特判。
4. 添加一个小型测试文件并运行适配器契约测试。
5. 在实验配置的 `models` 列表中启用模型。
6. 正式运行前记录模型版本、权重、初始化数据、生成命令和文件校验和。
